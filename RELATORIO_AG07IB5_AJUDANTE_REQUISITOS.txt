====================================================================
5. QUEM FORNECE AJUDANTE
====================================================================

NÃO IDENTIFICADO no contrato estruturural.

O campo "possui_ajudante" está no metadata do App, não em coluna estrutural.
Não é possível saber automaticamente se o prestador pode fornecer ajudante.

O campo "ajudantes" na alocação é preenchido MANUALMENTE pelo operador
(EscalaLista.tsx, linha 2466 — input number, default 0).

O operador decide quantos ajudantes alocar. O sistema NÃO auto-preenche
baseado em carga_ajudante.

====================================================================
6. REGRA DE BLOQUEIO IMPLEMENTADA
====================================================================

CONTRATO COMPROVADO:
  OS: carga_ajudante (bool) — campo estrutural, confiável
  Alocação: ajudantes (integer) — campo estrutural, confiável

REGRA:
  carga_ajudante = true + ajudantes = 0 → BLOQUEADO
  carga_ajudante = true + ajudantes > 0 → PERMITIDO
  carga_ajudante = false/null → não aplica (fail-open)

MOTIVO: ajudante_obrigatorio_ausente
MENSAGEM: "Esta operação exige ajudante — nenhum ajudante alocado"

GATE COLocado em:
  criarAlocacao (escalaService.ts, linha 384-390)

NÃO colocado em:
  trocarMotorista — ajudantes já alocados não mudam com troca de motorista
  trocarVeiculo — ajudantes já alocados não mudam com troca de veículo

JUSTIFICATIVA: a troca de motorista/veículo não invalida o requisito de
ajudante. O campo "ajudantes" permanece inalterado na alocação.
