3. DIAGNÓSTICO P1-02: CONTA_FINANCEIRA_ID = NULL NA BAIXA
============================================================

CAUSA RAIZ:
  receberService.baixarRecebivel() (linha 311) chamava RPC com:
    p_conta_financeira: extras?.conta || null  // UUID como TEXT
    // p_conta_financeira_id: NUNCA ENVIADO  ← BUG

  A UI (ContasReceberEnterprise.tsx:448-453) passava:
    conta: dadosBaixa.contaFinanceiraId  // UUID iba para o campo TEXT

  Resultado: financeiro_baixas.conta_financeira_id = NULL em TODAS
  as baixas de receber.

CORREÇÕES APLICADAS:

  3a. receberService.ts — ParamsBaixaRecebivel expandido:
      ✅ Adicionado campo: contaFinanceiraId?: string

  3b. receberService.ts — RPC call corrigida:
      ✅ Adicionado: p_conta_financeira_id: extras?.contaFinanceiraId || null
      ✅ p_conta_financeira preservado para retrocompatibilidade (TEXT name)

  3c. ContasReceberEnterprise.tsx — handlers de baixa corrigidos:
      ✅ handleBaixaParcial: busca nome da conta + passa contaFinanceiraId
      ✅ handleBaixaTotal: busca nome da conta + passa contaFinanceiraId
      ✅ Antes: { conta: dadosBaixa.contaFinanceiraId }
      ✅ Depois: { conta: contaSel?.nome, contaFinanceiraId: dadosBaixa.contaFinanceiraId }

VALIDAÇÃO:
  ✅ tsc --noEmit: 0 erros (post-correções)

4. MOCKCONTASBANCARIAS → DADOS REAIS
============================================================

PROBLEMA:
  ContasReceberEnterprise.tsx importava mockContasBancarias de types.ts
  (array hardcoded) para os dropdowns de Conta Financeira nos diálogos
  de Baixa e Nova Receita.

CORREÇÃO:
  ✅ Import adicionado: buscarContasBancariasConfig de configFinanceiraService
  ✅ State criado: contasBancarias (ContaBancariaFinanceira[])
  ✅ useEffect: buscarContasBancariasConfig().then(setContasBancarias)
  ✅ Dropdown baixa: contasBancarias.filter(c => c.ativa)
  ✅ Dropdown nova receita: contasBancarias.filter(c => c.ativa)

FLUXO CORRETO:
  UI → buscarContasBancariasConfig() → contas_financeiras WHERE ativa=true
  → dropdown popula com contas REAIS (Cora, etc.)
  → usuário seleciona conta → UUID armazenado no state
  → ao baixar: passa UUID + nome ao receberService
  → RPC grava conta_financeira_id UUID na financeiro_baixas
