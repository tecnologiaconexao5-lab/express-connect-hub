1. CAUSA RAIZ
================================================================

Em ContasPagar.tsx, um useEffect (antiga linha 630-633) referencia
periodoEfetivo.inicio e periodoEfetivo.fim no array de dependencias:

  useEffect(() => {
    fetchLancamentos();
    fetchPagoMes();
  }, [periodoEfetivo.inicio, periodoEfetivo.fim]);  // <-- ANTES da declaracao

Porem, a declaracao de periodoEfetivo (useMemo) occurs AFTER:

  const periodoEfetivo = useMemo(() => {             // <-- LINHA 647
    if (filtros.dataInicio && filtros.dataFim) {
      return { inicio: filtros.dataInicio, fim: filtros.dataFim };
    }
    return periodoMes;
  }, [filtros.dataInicio, filtros.dataFim, periodoMes]);

Em JavaScript/TypeScript, declaracoes com `const` NAO sao hoisted.
Durante o render, o React avalia o array de dependencias ANTES de
executar o useEffect. Nesse momento, periodoEfetivo ainda esta no
"temporal dead zone" → ReferenceError:

  Cannot access 'periodoEfetivo' before initialization
