SECAO 2 — CORRECAO IMPLEMENTADA
---------------------------------

CORRECAO= Chamar criarAlocacao/atualizarAlocacao do escalaService
          + mover setModalOpen(false) SOMENTE no caminho de sucesso
          + adicionar isSaving para double-submit protection

Detalhes:
  - CREATE: await criarAlocacao(payload) → verifica resultado.sucesso
  - UPDATE: await atualizarAlocacao(id, payload) → verifica resultado.sucesso
  - Sucesso: toast.success + setModalOpen(false) + loadAlocacoes()
  - Erro: toast.error + return (modal permanece aberto)
  - Exception: toast.error + finally (modal permanece aberto)
  - Double-submit: isSaving bloqueia botao durante operacao

MODAL_CLOSE_AFTER= SOMENTE apos resposta bem-sucedida do banco
  - CREATE: resultado.sucesso === true
  - UPDATE: resultado.sucesso === true
  - Exception: NAO fecha (return no catch)

SUCCESS_TOAST_AFTER= toast.success("Alocação criada/atualizada com sucesso!")

SAVE_ERROR_CLOSES_MODAL_AFTER= NO
  - catch: return (nao chega ao setModalOpen)
  - resultado.sucesso === false: return (nao chega ao setModalOpen)
  - finally: setIsSaving(false) apenas

FALSE_SUCCESS_POSSIBLE_AFTER= NO
  - Modal so fecha apos confirmacao real do banco
  - Erro mantem modal aberto com dados preservados

SAVE_ERROR_KEEPS_FIELDS= YES
  - return no catch/erro mantem state do form intacto
  - Usuario pode corrigir e tentar novamente

DOUBLE_SUBMIT_PROTECTION= isSaving state
  - Botao "Salvar na Grade" desabilitado durante save
  - Texto muda para "Salvando..."
  - finally setIsSaving(false) libera botao

REFETCH_AFTER_CONFIRMED_SAVE= loadAlocacoes() apos setModalOpen(false)

CREATE_PERSISTENCE_CONFIRMATION= resultado.sucesso de criarAlocacao()
UPDATE_PERSISTENCE_CONFIRMATION= resultado.sucesso de atualizarAlocacao()
