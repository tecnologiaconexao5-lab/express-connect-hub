1. RESUMO EXECUTIVO
-------------------
O seed de homologacao (scripts/tms013_seed_hml.mjs) foi elevado de
classificacao B (Idempotencia Parcial) para C (Idempotencia Completa)
conforme arquitetura aprovada no TMS-016.

O que mudou:
- Versionamento: nenhum -> TMS013-SEED-v2 + hash SHA256
- Controle de concorrencia: nenhum -> pg_try_advisory_lock
- Checkpoint por cenario: gate unico -> tabela _hml_seed_checkpoint
- Transacao por cenario: 1 transacao geral -> 1 transacao por cenario
- Retomada automatica: nao -> sim (skip concluidos, retry falhos)
- SAVEPOINT para opcionais: nao -> sim (2 cenarios)
- ON CONFLICT: 3 tabelas financeiras (mantido) -> idem
- Manifesto: nao -> JSON atomico com rename
- Cleanup: script separado -> atualizado para checkpoint

2. ARQUITETURA IMPLEMENTADA
----------------------------
main()
  -> 1. Verificar tabela _hml_seed_checkpoint (aborta se nao existir)
  -> 2. Adquirir pg_try_advisory_lock(20260729, 0) (aborta se ocupado)
  -> 3. Ler checkpoint atual -> Map<cenario, status>
  -> Para cada cenario 1..6:
      -> Se concluido -> pular
      -> Se falhou/pendente/novo -> executar
          -> BEGIN; Adquirir lock; Executar; COMMIT ou ROLLBACK
          -> Escrever checkpoint; Coletar manifesto
      -> Se falhou -> abortar seed
  -> 4. Construir manifesto JSON
  -> 5. Flush atomico (.tmp -> .json)
  -> 6. Liberar lock (finally)
