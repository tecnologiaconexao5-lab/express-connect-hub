2. A) COMERCIAL > PROPOSTAS — ListaPropostas.tsx
===============================================================
Fluxo do modal "Enviar PDF" (botao da toolbar, linha ~520):

  Dialog (onOpenChange bloqueia fechamento durante envio)
    -> Select opcional "Vincular a uma proposta" (propostaUploadId;
       sentinela __nenhuma__ porque o Select shadcn nao aceita value vazio)
    -> DocumentoUploadUniversal (drag-and-drop + input file + camera)
    -> enviarPropostaPdf(file):
         1. validarArquivoAnexo(file)      -> toast.error se vazio /
            > 50 MB / tipo invalido          (lib/anexoDocumento.ts)
         2. checagem extra de PDF           -> "Envie um arquivo PDF..."
         3. enviarDocumentoOperacional(...) -> SUPABASE STORAGE real
            bucket documentos_operacionais + insert documentos_metadata
            (categoria/departamento "Comercial")
         4. estado enviandoProposta -> rotulo "Enviando proposta e
            registrando metadados..."
         5. SUCESSO:
            - sem vinculo  -> toast "Proposta enviada para a Central de
                              Documentos"
            - com vinculo  -> atualiza a proposta no estado local:
                              ultimoDocumentoId (id do documento),
                              ultimoDocumentoNome, atualizadoEm e evento
                              em historico ("PDF enviado para a Central de
                              Documentos (<arquivo>)") => tabela
                              "dá refresh" + toast especifico
            - limpa propostaUploadId e fecha o Dialog
         6. FALHA -> toast.error com a mensagem do erro
         7. finally -> enviandoProposta = false

Observacoes:
- A lista de propostas e estado local (mockPropostas) — nao ha query de
  servidor para invalidar; o refresh = atualizar o estado local da
  proposta vinculada (campos ultimoDocumento* + historico).
- Select/propostaUploadId/ultimoDocumento* estavam importados/declarados
  mas orfaos no working tree; agora plenamente utilizados.

===============================================================
3. B) CADASTRO DE PRESTADORES — PrestadorDetalhe.tsx
===============================================================
Fluxo por card de documento (CNH, RG, comprovante etc.):

  Card onDragOver/onDragLeave/onDrop (destaque border-primary + ring)
    -> handleDocFile(tipo, file)
       -> validarArquivoAnexo(file)          -> toast.error (50 MB/tipo)
       -> prestador sem id -> anexo em documentosPendentes
          ("Aguardando Salvar")
       -> com id: docUploadProgress[tipo] + isUploading = true
       -> enviarDocumentoOperacionalPrestador({file, prestadorId, tipo})
          = SUPABASE STORAGE bucket documentos_operacionais
            + insert documentos_metadata + espelho na tabela legada
              documentos_prestadores
       -> atualiza documentosMetadata + estado local do prestador
          com status fixo "em_analise" (fonte oficial de revisao)
       -> toast.success "...enviado e registrado"
       -> ERRO -> toast.error (mensagem real do erro)
       -> finally -> libera docUploadProgress + isUploading

  Feedback visual: badge "Enviando..." (animate-pulse) no card durante o
  envio + spinner no botao Upload; input file disabled durante o envio.

Nao ha lacunas pendentes neste componente.
