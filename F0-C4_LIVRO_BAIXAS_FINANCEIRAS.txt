5) RPCs CRIADAS
   a) f_registrar_baixa_financeira(titulo_tabela, titulo_id, valor_baixado,
        data_baixa DEFAULT CURRENT_DATE, forma_pagamento, conta_financeira,
        referencia_bancaria, observacao, usuario_id, usuario_nome)

      TRANSACIONAL: trava o título (SELECT ... FOR UPDATE) → soma baixas não

      do título (tudo na MESMA transação; elimina "baixa gravada sem título
      atualizado" e corrida entre baixas concorrentes). Somente financeiro_pagar
      habilitado nesta missão.
   b) f_estornar_baixa_financeira(baixa_id, motivo_estorno DEFAULT NULL)
      RETURNS (sucesso, mensagem, saldo_restante, status_titulo)
      Marca estornada=true + data_estorno + motivo_estorno; NUNCA deleta;
      recalcula total baixado e saldo; devolve o título para aberto (sem baixas
      válidas, limpando data_pagamento/data_efetiva_pgto), parcial ou pago.

6) FÓRMULA UTILIZADA PARA SALDO
   total_baixado = SUM(valor_baixado) das baixas do título com estornada = false
   saldo         = financeiro_pagar.valor (valor_original) - total_baixado
   saldo_restante gravado na baixa = saldo após esta baixa (nunca negativo).
   O valor_original de cada baixa é o `valor` do título no momento da baixa
   (snapshot informativo; o cálculo usa sempre o valor vigente do título).

7) REGRAS DE BAIXA PARCIAL/TOTAL (múltiplas baixas agora suportadas)
   Exemplo validado: título R$ 1.000 →
     baixa R$ 300 → saldo R$ 700, status parcial
     baixa R$ 200 → saldo R$ 500, status parcial
     baixa R$ 500 → saldo R$ 0,   status pago
   Regras (NUNCA permitir):
     - baixa <= 0              → rejeitada ("Valor da baixa deve ser maior que zero");
     - baixa > saldo           → rejeitada ("Valor da baixa excede o saldo restante");
     - baixa em título cancelado → rejeitada;
     - baixa nova em título já quitado → rejeitada;
     - saldo negativo          → impossível (guarda no RPC + check constraint);
     - duplicação do valor original → não ocorre (valor nunca é alterado; só status).
   Cada baixa é um registro individual auditável em financeiro_baixas.

8) REGRA DE ESTORNO
