Data: 21/08/2026

============================================================
CAUSA-RAIZ
============================================================

Arquivo: src/lib/pdf/extratoPrestadorReport.ts
Stack:   linha 239, dentro do didDrawCell da tabela de RESUMO FINANCEIRO.

Chamada responsável (antes):

  doc.text(data.cell.text[1], data.cell.x + data.cell.width - 2, ...)

O didDrawCell é invocado pelo autoTable para CADA célula da linha
"SALDO LÍQUIDO" (summaryTableData.length - 2). A linha tem 2 células:

  1. coluna 0 (rótulo "SALDO LÍQUIDO");
  2. coluna 1 (valor "R$ ...").

Para a célula 0, data.cell.text possui APENAS 1 linha ('SALDO LÍQUIDO'),
portanto data.cell.text[1] === undefined. jsPDF.text recebe undefined
como primeiro argumento -> "Invalid arguments passed to jsPDF.text".

Para a célula 1, text[0] = valor, text[1] = undefined; além disso o valor
era desenhado à ESQUERDA (data.cell.x + 2) em vez de à direita, e a chamada
da direita quebrava no text[1].

Argumento inválido identificado: data.cell.text[1] === undefined
(linha única na célula do rótulo).

============================================================
CORREÇÃO (mínima, somente o didDrawCell responsável)
============================================================

Antes:
  const centroY = ...;
  doc.text(data.cell.text[0], data.cell.x + 2, centroY);            // esquerda
  doc.text(data.cell.text[1], data.cell.x + data.cell.width - 2, centroY, {align:'right'});

Depois:
  const textoSeguro = (data.cell.text || [])
    .flat()
    .filter(t => t !== undefined && t !== null)
    .map(t => String(t))
    .join(' ');
  const centroY = data.cell.y + data.cell.height / 2 + 1;
  ...
  if (data.column.index === 0) {
    if (textoSeguro) doc.text(textoSeguro, data.cell.x + 2, centroY);       // rótulo à esquerda
  } else if (textoSeguro) {
    doc.text(textoSeguro, data.cell.x + data.cell.width - 2, centroY, { align: 'right' }); // valor à direita
  }

- texto sempre convertido para string (String(t));
- undefined/null removidos;
- fallback vazio: só desenha se houver texto;
- coordenadas numéricas preservadas (data.cell.* são números do autoTable).

O segundo didDrawCell (coluna Tipo, operações) usa apenas
data.cell.text[0], que é sempre 'Crédito'/'Débito' definido; não era a
fonte do erro relatado e não foi alterado (correção mínima).
