2. COMPARAÇÃO — RPC SECURITY DEFINER x EDGE FUNCTION
----------------------------------------------------------------------------------------------------
2.1 RPC SECURITY DEFINER (Postgres)
  VANTAGENS
    - Transação atômica: validação + dedup + INSERT/UPDATE no mesmo commit.
    - Integridade forte: CHECK constraints, unique indexes, FKs e normalização SQL.
    - Sem deploy de runtime separado; versiona junto da migration.
    - Baixa latência; sem cold start.
    - Reutilizável pelo TMS e por scripts.
    - Fácil de testar com SQL/pgTAP.
  RISCOS
    - EXECUTE para anon expõe a função publicamente; qualquer cliente pode
      chamá-la (inclusive fora do formulário).
    - Captcha/rate limit/anti-spam são difíceis em PL/pgSQL; exigiriam tabela de
      rate limit, extensão HTTP (pg_net) ou validação no Edge.
    - Lógica de validação longa e mais difícil de evoluir.
    - SECURITY DEFINER exige cuidado com search_path e privilégios.
    - Observabilidade/telemetria mais pobre.
    - DoS: payloads grandes/loops podem consumir banco; precisa statement_timeout
      e limites.
  CONTROLES
    - `SET search_path = public, pg_temp`, sem SQL dinâmico.
    - EXECUTE apenas para service_role (Edge), nunca anon/authenticated.
    - Validação de enums, tamanhos, formatos e LGPD.
    - Unique parcial de identidade ativa + normalização.
    - `statement_timeout`, limites de tamanho.
    - Se anon for permitido: rate-limit table + captcha via Edge obrigatório.

2.2 EDGE FUNCTION (Deno/TypeScript)
  VANTAGENS
    - Endpoint HTTP controlado (CORS, método POST, limite de corpo).
    - Captcha (Turnstile/hCaptcha) e rate limit por IP hash no Edge.
    - Validação Zod/TS, mensagens claras e logs sem PII.
    - Segredos (service role) ficam no runtime do Edge, nunca no browser.
    - Pode chamar RPC transacional ou inserir com service_role.
    - Fácil de versionar/deployar e testar com Deno.
    - Permite bloquear/limitar abuso antes de tocar o banco.
  RISCOS
    - Deploy/versionamento separado; dependência de runtime.
    - Se usar service_role para INSERT direto, pode burlar RLS; precisa validação
      estrita e allowlist de colunas.
    - Se chamar RPC com anon, o atacante pode chamar a RPC direto; por isso a RPC
      deve ser service_role-only e o Edge a única entrada pública.
    - Cold start e indisponibilidade do Edge bloqueiam o canal.
    - Sem transação multi-statement se fizer várias chamadas; usar RPC para isso.
  CONTROLES
    - CORS restrito ao domínio público.
    - Rate limit por IP hash (tabela/RPC ou Upstash/Redis).
    - Captcha obrigatório.
    - Zod + validação de enums/limites.
    - Chamar RPC SECURITY DEFINER com service_role; nenhum INSERT direto.
    - Não logar PII; retornar apenas protocolo/id.
    - Timeout, limite de body e de campos.

2.3 RECOMENDAÇÃO
  HÍBRIDO: Edge Function pública `ofertas-publicas` + RPC
  `f_registrar_oferta_publica` (SECURITY DEFINER, EXECUTE somente service_role).
  - O browser chama somente a Edge Function.
  - A Edge valida/captcha/rate limit e chama a RPC com service_role.
  - A RPC é a única que escreve, com validação/dedup/transação.
  - `anon` NÃO recebe EXECUTE da RPC nem INSERT direto em tabela.
  Isso combina anti-abuso (Edge) com integridade (RPC/DB).
  Custo: um deploy de Edge; benefício: segurança e integridade muito superiores
  ao RPC público puro.

  Alternativa aceitável para MVP sem Edge: RPC pública com rate-limit table e
  captcha via proxy, mas é inferior em anti-spam/observabilidade. Não recomendada
  para produção.

  - Unique parcial:

  - Se já existir oferta ativa com a mesma chave: atualizar a oferta existente
    (merge), registrar evento no `historico`, retornar o mesmo protocolo e
    `deduplicada: true`.
  - Se existirem múltiplas ofertas históricas/arquivadas, permitir nova oferta
    ativa; não apagar histórico.
  - Se houver conflito entre identidades (ex.: mesmo telefone, CPF diferente),
    NÃO fundir automaticamente: marcar `revisao_humana=true` no retorno/histórico.

8. SEGURANÇA, LGPD E ANTI-ABUSO
----------------------------------------------------------------------------------------------------
8.1 EDGE FUNCTION (PÚBLICA)
  - POST apenas; CORS restrito ao domínio do formulário.
  - Limite de corpo (ex.: 32 KB) e de campos.
  - Zod: enums, tamanhos, formatos, valores >= 0, dias 0..6, UF 2 letras.
  - Captcha obrigatório (Turnstile/hCaptcha) verificado no Edge.
  - Rate limit por IP hash (ex.: 5/min, 20/dia) em tabela/Redis.
  - Honeypot/field timing (opcional).
  - Não logar PII; logar protocolo, status, ip_hash, latência.
  - Em sucesso, retornar apenas `{ protocolo }`.
  - Chama RPC com service_role; nunca expõe service role ao browser.
8.2 RPC (SERVICE_ROLE ONLY)
  - SECURITY DEFINER, `SET search_path = public, pg_temp`.
  - EXECUTE somente `service_role`; `REVOKE` de PUBLIC/anon/authenticated.
  - Sem SQL dinâmico; validação explícita; `statement_timeout`.
  - Normalização/dedup/upsert na mesma transação.
  - Não retorna dados de outras ofertas; retorna protocolo/id/flag dedup.
8.3 TABELA/RLS
  - RLS ON.
  - SELECT/UPDATE somente `authenticated` TMS com
    `tenant_id = current_tenant_id_safe()`.
  - Sem policies/grants para `anon`.
  - INSERT apenas via RPC/service_role (sem policy de INSERT para authenticated,
    a menos que se queira entrada manual TMS; decidir na 02B.1).
  - DELETE somente service_role/admin (se necessário); preferir arquivar.
8.4 LGPD
  - Consentimento explícito, finalidade, versão do termo e data.
  - Minimização: sem documentos no público; apenas contato/oferta.
  - Retenção definida (ex.: 12 meses após último contato; arquivar/anonymizar).
  - Direito de exclusão/atualização via canal de contato/TMS.
  - IP apenas em hash; não armazenar IP puro.
  - Acesso TMS por tenant; auditoria de leitura/exportação (futuro).

CREATE OR REPLACE FUNCTION public.f_registrar_oferta_publica(
  p_tenant_id UUID,
  p_tipo_oferta TEXT,
  p_nome TEXT,
  p_cpf_cnpj TEXT DEFAULT NULL,
  p_telefone TEXT DEFAULT NULL,
  p_email TEXT DEFAULT NULL,
  p_cidade TEXT DEFAULT NULL,
  p_uf TEXT DEFAULT NULL,
  p_regioes JSONB DEFAULT '[]'::jsonb,
  p_dias_disponiveis JSONB DEFAULT '[]'::jsonb,
  p_horario_inicio TIME DEFAULT NULL,
  p_horario_fim TIME DEFAULT NULL,
  p_modalidades TEXT[] DEFAULT '{}',
  p_valor_diaria NUMERIC DEFAULT NULL,
  p_valor_km NUMERIC DEFAULT NULL,
  p_valor_saida NUMERIC DEFAULT NULL,
  p_valor_mensal NUMERIC DEFAULT NULL,
  p_condicoes TEXT DEFAULT NULL,
  p_restricoes TEXT DEFAULT NULL,
  p_veiculo_tipo TEXT DEFAULT NULL,
  p_veiculo_categoria TEXT DEFAULT NULL,
  p_veiculo_modelo TEXT DEFAULT NULL,
  p_veiculo_placa TEXT DEFAULT NULL,
  p_veiculo_ano INTEGER DEFAULT NULL,
  p_capacidade_kg NUMERIC DEFAULT NULL,
  p_capacidade_m3 NUMERIC DEFAULT NULL,
  p_capacidade_bau_litros NUMERIC DEFAULT NULL,
  p_dimensoes JSONB DEFAULT '{}'::jsonb,
  p_caracteristicas JSONB DEFAULT '[]'::jsonb,
  p_lgpd_consent BOOLEAN DEFAULT FALSE,
  p_lgpd_termo_versao TEXT DEFAULT NULL,
  p_ip_hash TEXT DEFAULT NULL,
  p_user_agent_hash TEXT DEFAULT NULL
) RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public, pg_temp
AS $$
DECLARE
  v_cpf TEXT;
  v_tel TEXT;
  v_email TEXT;
  v_chave TEXT;
  v_protocolo TEXT;
  v_id UUID;
  v_existente RECORD;
  v_hist JSONB;
  v_agora TIMESTAMPTZ := now();
BEGIN
  IF p_tenant_id IS NULL THEN
    RAISE EXCEPTION 'tenant_obrigatorio';
  END IF;
  IF p_lgpd_consent IS DISTINCT FROM TRUE THEN
    RAISE EXCEPTION 'lgpd_obrigatorio';
  END IF;
  IF p_tipo_oferta NOT IN ('motoboy','motorista','veiculo') THEN
    RAISE EXCEPTION 'tipo_oferta_invalido';
  END IF;
  IF length(trim(coalesce(p_nome,''))) < 3 THEN
    RAISE EXCEPTION 'nome_invalido';
  END IF;

  v_cpf := nullif(regexp_replace(coalesce(p_cpf_cnpj,''), '\D', '', 'g'), '');
  v_tel := nullif(regexp_replace(coalesce(p_telefone,''), '\D', '', 'g'), '');
  v_email := nullif(lower(trim(coalesce(p_email,''))), '');

  IF v_cpf IS NOT NULL AND length(v_cpf) NOT IN (11,14) THEN
    RAISE EXCEPTION 'cpf_cnpj_invalido';
  END IF;
  IF v_tel IS NOT NULL AND length(v_tel) NOT BETWEEN 10 AND 11 THEN
    RAISE EXCEPTION 'telefone_invalido';
  END IF;
  IF v_email IS NOT NULL AND v_email !~ '^[^@\s]+@[^@\s]+\.[^@\s]+$' THEN
    RAISE EXCEPTION 'email_invalido';
  END IF;
  IF v_cpf IS NULL AND v_tel IS NULL AND v_email IS NULL THEN
    RAISE EXCEPTION 'contato_obrigatorio';
  END IF;

  v_chave := CASE
    WHEN v_cpf IS NOT NULL THEN CASE WHEN length(v_cpf)=11 THEN 'cpf:' ELSE 'cnpj:' END || v_cpf
    WHEN v_tel IS NOT NULL THEN 'tel:' || v_tel
    ELSE 'email:' || v_email
  END;

  v_protocolo := 'OF-' || to_char(v_agora, 'YYYYMMDD') || '-' ||
    upper(substr(replace(gen_random_uuid()::text, '-', ''), 1, 8));

  v_hist := jsonb_build_array(jsonb_build_object(
    'tipo', 'oferta_recebida',
    'descricao', 'Oferta recebida pelo link público.',
    'data', v_agora
  ));

  SELECT * INTO v_existente
  FROM public.recrutamento_ofertas
  WHERE tenant_id = p_tenant_id
    AND chave_identidade = v_chave
    AND status IN ('nova','em_analise','em_contato')
  FOR UPDATE
  LIMIT 1;

  IF v_existente.id IS NOT NULL THEN
    UPDATE public.recrutamento_ofertas
       SET nome = trim(p_nome),
           cpf_cnpj = nullif(trim(coalesce(p_cpf_cnpj,'')), ''),
           cpf_cnpj_norm = v_cpf,
           telefone = nullif(trim(coalesce(p_telefone,'')), ''),
           telefone_norm = v_tel,
           email = nullif(trim(coalesce(p_email,'')), ''),
           email_norm = v_email,
           cidade = nullif(trim(coalesce(p_cidade,'')), ''),
           uf = nullif(upper(trim(coalesce(p_uf,''))), ''),
           regioes = coalesce(p_regioes, '[]'::jsonb),
           dias_disponiveis = coalesce(p_dias_disponiveis, '[]'::jsonb),
           horario_inicio = p_horario_inicio,
           horario_fim = p_horario_fim,
           modalidades = coalesce(p_modalidades, '{}'),
           valor_diaria = p_valor_diaria,
           valor_km = p_valor_km,
           valor_saida = p_valor_saida,
           valor_mensal = p_valor_mensal,
           condicoes = nullif(trim(coalesce(p_condicoes,'')), ''),
           restricoes = nullif(trim(coalesce(p_restricoes,'')), ''),
           veiculo_tipo = nullif(trim(coalesce(p_veiculo_tipo,'')), ''),
           veiculo_categoria = nullif(trim(coalesce(p_veiculo_categoria,'')), ''),
           veiculo_modelo = nullif(trim(coalesce(p_veiculo_modelo,'')), ''),
           veiculo_placa = nullif(upper(trim(coalesce(p_veiculo_placa,''))), ''),
           veiculo_ano = p_veiculo_ano,
           capacidade_kg = p_capacidade_kg,
           capacidade_m3 = p_capacidade_m3,
           capacidade_bau_litros = p_capacidade_bau_litros,
           dimensoes = coalesce(p_dimensoes, '{}'::jsonb),
           caracteristicas = coalesce(p_caracteristicas, '[]'::jsonb),
           lgpd_consent = TRUE,
           lgpd_consent_em = coalesce(lgpd_consent_em, v_agora),
           lgpd_termo_versao = p_lgpd_termo_versao,
           ip_hash = p_ip_hash,
           user_agent_hash = p_user_agent_hash,
           historico = coalesce(historico, '[]'::jsonb) || v_hist,
           updated_at = v_agora
     WHERE id = v_existente.id
     RETURNING id INTO v_id;

    RETURN jsonb_build_object(
      'success', true, 'oferta_id', v_id,
      'protocolo', v_existente.protocolo, 'deduplicada', true
    );
  END IF;

  INSERT INTO public.recrutamento_ofertas (
    protocolo, tenant_id, tipo_oferta, status, nome, cpf_cnpj, cpf_cnpj_norm,
    telefone, telefone_norm, email, email_norm, cidade, uf, regioes,
    dias_disponiveis, horario_inicio, horario_fim, modalidades,
    valor_diaria, valor_km, valor_saida, valor_mensal, condicoes, restricoes,
    veiculo_tipo, veiculo_categoria, veiculo_modelo, veiculo_placa, veiculo_ano,
    capacidade_kg, capacidade_m3, capacidade_bau_litros, dimensoes,
    caracteristicas, lgpd_consent, lgpd_consent_em, lgpd_termo_versao,
    chave_identidade, ip_hash, user_agent_hash, historico
  ) VALUES (
    v_protocolo, p_tenant_id, p_tipo_oferta, 'nova', trim(p_nome),
    nullif(trim(coalesce(p_cpf_cnpj,'')), ''), v_cpf,
    nullif(trim(coalesce(p_telefone,'')), ''), v_tel,
    nullif(trim(coalesce(p_email,'')), ''), v_email,
    nullif(trim(coalesce(p_cidade,'')), ''), nullif(upper(trim(coalesce(p_uf,''))), ''),
    coalesce(p_regioes, '[]'::jsonb), coalesce(p_dias_disponiveis, '[]'::jsonb),
    p_horario_inicio, p_horario_fim, coalesce(p_modalidades, '{}'),
    p_valor_diaria, p_valor_km, p_valor_saida, p_valor_mensal,
    nullif(trim(coalesce(p_condicoes,'')), ''), nullif(trim(coalesce(p_restricoes,'')), ''),
    nullif(trim(coalesce(p_veiculo_tipo,'')), ''),
    nullif(trim(coalesce(p_veiculo_categoria,'')), ''),
    nullif(trim(coalesce(p_veiculo_modelo,'')), ''),
    nullif(upper(trim(coalesce(p_veiculo_placa,''))), ''),
    p_veiculo_ano, p_capacidade_kg, p_capacidade_m3, p_capacidade_bau_litros,
    coalesce(p_dimensoes, '{}'::jsonb), coalesce(p_caracteristicas, '[]'::jsonb),
    TRUE, v_agora, p_lgpd_termo_versao, v_chave, p_ip_hash, p_user_agent_hash, v_hist
  ) RETURNING id INTO v_id;

  RETURN jsonb_build_object(
    'success', true, 'oferta_id', v_id,
    'protocolo', v_protocolo, 'deduplicada', false
  );
END;
$$;
