================================================================================
4. CONTA CORRENTE — LÓGICA
================================================================================

4.1 — ESTRUTURA DO EXTRATO
  Cada registro gera:
    - ID: pagamento.id
    - Data: periodo_inicio
    - Origem: tipo_lancamento
    - Descrição: "Serviço" | "Pagamento" | "Cancelamento"
    - Crédito: natureza == "credito" ? valor_liquido : 0
    - Débito: status_pagamento == "pago" ? valor_liquido : 0
    - Saldo: acumulado cronológico (créditos - débitos)

4.2 — REGRAS
  - Serviço aprovado = CRÉDITO
  - Ajuste positivo = CRÉDITO
  - Desconto/negativo = DÉBITO
  - Pagamento = DÉBITO
  - Saldo = créditos - débitos (cronológico)

4.3 — IDEMPOTÊNCIA
  - Pagamento já registrado não gera segundo débito
  - Status "cancelado" não gera débito nem crédito
