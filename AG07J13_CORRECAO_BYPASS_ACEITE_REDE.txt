GATES ADICIONADOS (7 validações, todas BEFORE any write):

1. PRESTADOR ATIVO + LIBERADO_APP
   - SELECT status, liberado_app FROM prestadores WHERE id = p_prestador_id
   - status != 'ativo' → RECUSA
   - liberado_app != true → RECUSA

2. VEÍCULO VINCULADO
   - SELECT FROM veiculos WHERE prestador_vinculado = p_prestador_id AND status = 'disponivel' ORDER BY principal DESC LIMIT 1
   - NOT FOUND → RECUSA

3. TIPO VEÍCULO
   - LOWER(TRIM(veiculos.tipo_veiculo)) vs LOWER(TRIM(os.veiculo_tipo))
   - match exato; OS sem tipo → PASS; veículo sem tipo → RECUSA

4. CAPACIDADE KG
   - veiculos.capacidade_kg >= os.peso (quando ambos > 0)

5. CAPACIDADE M3
   - veiculos.capacidade_m3 >= os.cubagem (quando ambos > 0)

6. CAPACIDADE TÉRMICA
   - os.carga_refrigerada=true OU os.veiculo_termica IN ('refrigerado','congelado','termico')
   - → veiculos.tipo_carga deve ser 'refrigerado'/'congelado'/'termico'
   - seco → RECUSA; NULL/desconhecido → RECUSA

7. AJUDANTE
   - os.carga_ajudante=true → RECUSA (aceite via Rede cria com ajudantes=0)
