## 3. CONTRATO FLUTTER — VALIDAÇÃO

### Chamada real do App (produção)
```dart
// driver_operations_repository.dart:59
final response = await SupabaseService().client.rpc(
  'f_buscar_operacoes_motorista',
);
// 0 parâmetros
```

### Envelope esperado pelo App
```json
{
  "success": true,         // ← inglês, NÃO "sucesso"
  "operacoes": [...],      // ← array de operações
  "total": 49              // ← contagem
}
```

### Tratamento de erro pelo App
| Resposta | Comportamento |
|----------|---------------|
| `success == true` | Retorna `operacoes` como `List<DriverOperation>` |
| `error == 'PRESTADOR_NAO_ENCONTRADO'` | Retorna `[]` silenciosamente |
| Outro erro | `throw StateError('SERVER_ERROR: ...')` |
| Resposta não-Map | `throw StateError('UNEXPECTED_RESPONSE')` |

### Corresponde à migration corrigida?
✅ **SIM** — Overload 0-param agora retorna JSONB com `{ success, operacoes, total }`.

| Status da alocação | Elegível | Inelegível |
|---------------------|:--------:|:----------:|
| `planejada` | ✅ Retorna | ❌ Oculta |
| `aguardando_aceite` | ✅ Retorna | ❌ Oculta |
| `aceita` | ✅ Retorna | ❌ Oculta |
| `em_rota` | ✅ Retorna | ✅ **Preserva** |
| `ocorrencia` | ✅ Retorna | ✅ **Preserva** |
| `concluida` | ✅ Retorna | ❌ Oculta |
| `cancelada` | ❌ Oculta | ❌ Oculta |
| `recusada` | ❌ Oculta | ❌ Oculta |

### Lógica de preservação
- **Elegível**: vê tudo exceto `cancelada`/`recusada` (terminal morto)
- **Inelegível**: vê APENAS `em_rota`/`ocorrencia` (operação em curso que precisa concluir)
- O App permite conclusão segura mesmo com prestador bloqueado
