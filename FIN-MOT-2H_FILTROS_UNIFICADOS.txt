============================================================
O QUE FOI FEITO
============================================================

Eliminada a duplicidade de filtros entre o painel "Fechamentos e
Pagamentos" e o modal "Gerar Extrato do Período".

1) Barra superior unificada (única), com os mesmos estados para
   painel e extrato:
   - Prestador (Select, com "Todos os prestadores")
   - Período
   - Data Início
   - Data Fim
   - Cliente (Select, com "Todos os clientes")
   - Origem/Tipo (Todos / Ordem de Serviço / Escala / Lançamento Manual)
   - Atualizar
   - Gerar Extrato

2) Removido o modal de seleção duplicado que pedia novamente
   Prestador, Data inicial, Data final, Cliente e Origem/Tipo.

3) Botão "Gerar Extrato":
   - usa diretamente os filtros da tela;
   - se Prestador = Todos (vazio), mostra aviso "Selecione um
     prestador para gerar o extrato" (não gera relatório agregado);
   - se prestador selecionado, chama o service com os filtros atuais
     e abre o modal EXISTENTE já com o extrato montado;
   - "Gerar PDF Completo" permanece dentro do modal.

4) Estados NÃO duplicados:
   - removido o estado `extratoPeriodo` (objeto separado);
   - filtros de prestador/cliente/origem agora vivem em
     `filtroPrestadorId`, `filtroClienteId`, `filtroOrigem`;
   - datas compartilham `dataInicio`/`dataFim` já usadas pelo painel;
   - `Atualizar` continua alimentando a tela (fetchOss + fetchPagamentos)
     com as mesmas datas.
