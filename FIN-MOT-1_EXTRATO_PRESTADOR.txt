# FIN-MOT-1 — Extrato de Fechamento do Prestador
**Data:** 21 de agosto de 2026  
**Status:** ✅ Implementação concluída  
**Missão:** Implantar um Extrato de Fechamento do Prestador profissional, detalhado e rastreável no TMS

## Objetivo
Criar um sistema completo para geração, visualização e gestão de extratos de fechamento para prestadores, integrando dados reais do TMS (OS, Escala, operações, valores) em um documento profissional PDF com rastreabilidade completa.

## Arquitetura Implementada

### 1. **Estrutura de Banco de Dados**
- Migration SQL `20260821_fin_mot_1_extrato_fechamento_prestador.sql`:
  - Tabela `fechamentos_prestador`: dados principais do extrato
  - Tabela `itens_fechamento_prestador`: operações detalhadas
  - Tabela `movimentos_conta_corrente_prestador`: registro de movimentos
  - Triggers para validação e auditoria
  - RLS policies para segurança
  - Função `gerar_numero_fechamento_prestador`: sequência FP-YYYY-######

### 2. **Serviço Principal**
`src/services/financeiro/extratoPrestadorService.ts`:
- **Interfaces completas** com tipos TypeScript
- **Métodos principais**:
  - `criarExtrato()`: consolida operações do período
  - `salvarExtrato()`: persistência com upsert
  - `buscarExtratoPorId()`: consulta completa com joins
  - `listarExtratos()`: filtros por período/status/prestador
  - `atualizarStatus()`: controle workflow
  - `excluirExtrato()`: exclusão segura
- **Funções auxiliares**:
  - `buscarDadosPrestador()`: dados básicos do prestador
  - `buscarOperacoesPeriodo()`: consulta alocações_escala + OS
  - `calcularResumoFinanceiro()`: agregação créditos/débitos

## Funcionalidades Implementadas

### ✅ **Geração de Extrato**
- Consolidação automática de operações por período
- Cálculo automático de créditos (serviços, pedágio, adicionais, reembolsos)
- Cálculo automático de débitos (descontos, adiantamentos, combustível)
- Saldo líquido calculado em tempo real

### ✅ **Controle de Workflow**
- Status do extrato: `em_conferencia`, `conferido`, `aprovado`, `cancelado`
- Status de pagamento: `pendente`, `programado`, `em_lote`, `pago`, `cancelado`
- Status de aprovação: `pendente`, `aprovado`, `reprovado`
- Data de geração e data de pagamento rastreadas

### ✅ **Visualização e Filtros**
- Filtro por período (mês atual, personalizado, últimos 30/60 dias)
- Filtro por status (todos os status)
- Busca por prestador específico
- Ordenação por data de geração e valor
- Paginação automática

### ✅ **Geração de PDF**
- Documento A4 profissional com logo da empresa
- Layout estruturado com seções claras
- Tabelas legíveis com cores corporativas
- Mascaramento de dados sensíveis (CPF/CNPJ)
- Nome do arquivo descritivo: `Extrato_FP-2024-000123_Joao_Silva.pdf`

### ✅ **Integração com Dados Existentes**
- **Fontes de dados reais**:
  - `alocacoes_escala`: operações e valores base
  - `ordens_servico`: dados da OS vinculada
  - `prestadores`: dados cadastrais
  - `clientes`: nome do cliente
  - `financeiro_pagar`: dados financeiros consolidados
- **Sem dados duplicados**: tudo consultado em tempo real
