BUGS FOUND (DURING DEVELOPMENT)
═══════════════════════════════════════════════════════════════

1. Filtro FaturaLista usa f.numero (NULL para manual), não metadata.numeroManual
   • Impacto: filtro "Número" não encontra faturas manuais
   • Arquivo: FaturaLista.tsx:99
   • Status: DOCUMENTADO (não corrigido — fora do escopo FIN-362.3C)

2. Coluna ie vs inscricao_estadual
   • Teste usava c.inscricao_estadual — coluna real é c.ie
   • Corrigido no spec

3. SearchableSelect é <Input>, não button[role="combobox"]
   • Teste anterior buscava combobox — cliente nunca era selecionado
   • Corrigido: input[placeholder*="Pesquisar cliente"]

4. Editar fatura emitida não mostra campos editáveis
   • podeEditar = f.status === "rascunho" (FaturaPanel.tsx:345)
   • Emitida fatura → pencil abre FaturaPanel SEM campos de edição
   • Correção do teste: criar como rascunho primeiro, editar, depois emitir

5. "Salvar e Gerar PDF" requer dadosEmpresa !== null
   • handleSalvarEGerarPDF: if (!validar() || !dadosEmpresa) return (silently)
   • buscarDadosEmpresaParaFatura() retorna objeto sempre (não null)
   • Não foi bloqueador — mas guarda é silencioso (sem toast)

KEY FINDINGS
═══════════════════════════════════════════════════════════════

• FaturaManualDialog: 100% funcional para criação de rascunho
  - Client selection via SearchableSelect (input-based, not combobox)
  - Account auto-selected by carregarBase() from contas_financeiras
  - Validation: numero + numeroChecado + clienteId + valor > 0 + vencimento

• FaturaPanel: funcional para edição de RASCUNHO
  - Edit fields: Modelo (select), Data Emissão (date), Vencimento (date), Observação (textarea)
  - Descrição textarea only visible for modelo="calvo" (not conexao_express)
  - "Emitir" button present for rascunho status
  - "Baixar PDF" available for all statuses

• PDF generation: client-side via jsPDF (pdfFatura.ts)
  - Download triggered by doc.save() → browser download event
  - Empresa data from configuracoes_fiscais + contas_financeiras
  - Client address from enderecos_clientes (fixed BUG-2 in FIN-01.1)
  - Bank data snapshot stored in metadata.contaBancaria

• Edit flow constraint: only rascunho faturas can be edited
  - podeEditar = fatura?.status === "rascunho" (FaturaPanel.tsx:345)
  - Emitida faturas: pencil opens panel but NO edit fields
  - This is by design (documented in FIN-01.1)
