FIN-MOT-2F — LUNA FIX CRASH EXTRATO DO PRESTADOR
Data: 21/08/2026
Status: B — CORRIGIDO NO CÓDIGO, MAS NÃO COMPROVADO NO NAVEGADOR

============================================================
CAUSA-RAIZ
============================================================

Componente: modal "Gerar Extrato do Período" dentro de
PagamentoPrestadores.

Arquivo: src/components/financeiro/PagamentoPrestadores.tsx

Linha identificada antes da correção: 2343.

Select responsável: filtro "Cliente (opcional)".

Valor inválido:

  <SelectItem value="">Todos os clientes</SelectItem>

O Radix Select não aceita string vazia como valor de Select.Item.
Quando o SelectContent do filtro Cliente é montado, o Radix lança:

  A <Select.Item /> must have a value prop that is not an empty string

Por que a tentativa anterior não resolveu:

Ela tratou a ausência de cliente na chamada do serviço com `clienteId ||
undefined`, mas o problema ocorria antes, na árvore React do modal. O item
literal `<SelectItem value="">` continuou sendo renderizado fisicamente.
Além disso, os mapas de Prestador e Cliente aceitavam registros com `id`
nulo/vazio, que poderiam produzir outro `SelectItem` inválido.

Observação de reprodução: a inspeção estática confirmou o `SelectItem` literal
e sua linha exata. A reprodução autenticada no navegador não foi concluída
nesta sessão porque as variáveis `PLAYWRIGHT_TAMIRIS_PASSWORD` e
`PLAYWRIGHT_FINANCEIRO_PASSWORD` estão ausentes no ambiente local. Portanto,
este relatório não inventa stack de navegador nem marca a correção como
homologada visualmente.

============================================================
CORREÇÃO
============================================================

Arquivo alterado:

  src/components/financeiro/PagamentoPrestadores.tsx

Antes:

  clienteId: ""
  <SelectItem value="">Todos os clientes</SelectItem>
  prestadores.map(p => <SelectItem value={p.id}>...</SelectItem>)
  clientes.map(c => <SelectItem value={c.id}>...</SelectItem>)
  clienteId: extratoPeriodo.clienteId || undefined

Depois:

  const TODOS_CLIENTES_VALUE = "__todos_clientes__";
  clienteId: TODOS_CLIENTES_VALUE
  <SelectItem value={TODOS_CLIENTES_VALUE}>Todos os clientes</SelectItem>
  prestadores.filter(p => Boolean(p.id?.trim())).map(...)
  clientes.filter(c => Boolean(c.id?.trim())).map(...)
  clienteId: extratoPeriodo.clienteId === TODOS_CLIENTES_VALUE
    ? undefined
    : extratoPeriodo.clienteId

O sentinel só existe no estado/UI. Nunca é enviado ao Supabase. Para o filtro
de todos os clientes, o service recebe `undefined`, que representa ausência de
filtro. Registros de prestador ou cliente sem ID não geram SelectItem.

Os valores de Origem/Tipo já eram não vazios:

  todos
  ordem_servico
  escala
  manual

O Select de Prestador mantém estado inicial vazio no Root, o que é permitido
pelo Radix; somente os Select.Item são obrigados a ter valor não vazio.
