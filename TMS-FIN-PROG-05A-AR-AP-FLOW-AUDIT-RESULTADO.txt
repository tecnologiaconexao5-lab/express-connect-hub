2. M66 COMPLETO — f_trg_propagar_financeiro_alocacao (sha256:cd7e84c87efbca5f)
--------------------------------------------------------------------------------
Trigger: AFTER INSERT OR UPDATE OF (status, finalizada, valor_frete,
  valor_repasse, valor_pedagio, valor_combustivel, valor_ajudante,
  valor_adicional, valor_desconto, valor_desconto_prestador, tipo_reversa,
  reversa_valor_cliente, reversa_valor_prestador, prestador_id)
  ON public.alocacoes_escala FOR EACH ROW.
  enabled=O (normal).

Fluxo:
  - IF NEW.status='cancelada' -> RETURN (nao propaga).
  - Valores: v_valor_cliente=valor_frete(+reversa); v_valor_prestador=
    valor_repasse(+reversa); pedagio/adicional/ajudante/desconto.
  - Se todos zero -> RETURN.
  - v_is_concluida = (status='concluida' AND finalizada=true).
  - v_status_financeiro = 'aberto' se concluida senao 'pendente'.
  - Chave: se ordem_servico_id NOT NULL -> os_id = ordem_servico_id;
    senao os_id = id da PROPRIA alocacao.
  - v_outros_custos = adicional + ajudante - desconto_prestador.
  - v_valor_liquido = valor_prestador + pedagio + outros_custos.

EFEITOS COLATERAIS (por tabela):
  1) ordens_servico (SIDE EFFECT): INSERT ... ON CONFLICT(id) DO UPDATE. Se a
     alocacao nao tem OS, cria uma OS com o MESMO id da alocacao; depois
     UPDATE alocacoes_escala.ordem_servico_id. Esse INSERT dispara o M80.
  2) financeiro_receber: INSERT (os_id, 'Faturamento OS-ALOC-...', v_valor_cliente,
     venc=CURRENT_DATE+30, status=v_status_financeiro, cliente/cliente_id)
     ON CONFLICT (os_id) DO UPDATE ... WHERE status NOT IN ('pago','recebido','cancelada').
     -> Idempotencia por UNIQUE(os_id). NAO usa fatura_id.
  3) financeiro_pagar: INSERT (os_id, valor=v_valor_liquido, fornecedor_id=
     prestador_id, desconto=v_desconto) ON CONFLICT (os_id) DO UPDATE ...
     WHERE status NOT IN ('pago','parcial','cancelado','cancelada').
  4) pagamentos_prestadores: INSERT (os_id, valor_liquido, valor_servicos,
     pedagio, adicionais=outros, status_conferencia=em_aberto|pendente,
     status_pagamento=pendente|nao_vencido, origem_lancamento='escala_direta').
     ON CONFLICT (os_id) DO UPDATE ... WHERE status_pagamento NOT IN ('pago','cancelado').
  5) composicao_financeira_os: SOMENTE se concluida e valor_cliente>0.
     origem_calculo='escala_direta'.
Tratamento de erro: EXCEPTION WHEN OTHERS THEN RAISE (re-propaga; NAO silencia).

3. M80 COMPLETO — f_trg_propagar_financeiro_os (sha256:aa81948870a8b6b5)
--------------------------------------------------------------------------------
Trigger: AFTER INSERT OR UPDATE OF (valor_cliente, custo_prestador, pedagio,
  adicionais, ajudante, descontos, status) ON public.ordens_servico
  FOR EACH ROW WHEN (NEW.status IS DISTINCT FROM 'cancelada').
  enabled=O (normal).

Fluxo:
  - IF status='cancelada' -> RETURN.
  - v_valor_cliente=valor_cliente; v_valor_prestador=custo_prestador.
    Se ambos zero -> RETURN.
  - v_is_finalizada = (status='finalizada').
  - v_outros_custos = adicionais(jsonb) + ajudante(jsonb) - descontos.
  - v_valor_liquido = custo_prestador + pedagio + outros_custos.

EFEITOS (por tabela):
  1) financeiro_receber: PERFORM 1 by os_id; se nao existe INSERT
     (os_id=NEW.id, valor=valor_cliente, venc=+30, status aberto|pendente,
     cliente/cliente_id); senao UPDATE ... WHERE status NOT IN ('pago','recebido','cancelada').
     -> Idempotencia por check-then-insert (nao ON CONFLICT) + UNIQUE(os_id).
  2) financeiro_pagar: idem (se custo_prestador>0 e prestador_id not null).
  3) pagamentos_prestadores: INSERT origem_lancamento='os_direta',
     status_conferencia='em_aberto', status_pagamento='pendente'.
  4) composicao_financeira_os: SOMENTE se finalizada e valor_cliente>0;
     origem_calculo='os_direta'.
Tratamento de erro: SEM EXCEPTION WHEN OTHERS (erro propaga naturalmente).

CONVERGENCIA M66<->M80: quando o M66 cria a OS (alocacao sem OS), o M80 dispara
nesse INSERT; ambos usam a MESMA chave (os_id = id da alocacao). O UNIQUE(os_id)
+ ON CONFLICT/check-then-insert convergem para UMA linha por tabela. Nao ha
duplicacao por os_id, mas ha DOIS autores para a mesma linha.
