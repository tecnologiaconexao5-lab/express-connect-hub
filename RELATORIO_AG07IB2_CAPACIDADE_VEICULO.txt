====================================================================
5. REGRA DE PESO
====================================================================

capacidadeVeiculoCompativel(pesoOs, capacidadeKg, ...):

  pesoOs > 0 AND capacidadeKg > 0:
    pesoOs <= capacidadeKg → ✅ COMPATÍVEL
    pesoOs >  capacidadeKg → ❌ capacidade_peso_insuficiente
    Mensagem: "Carga (X kg) excede capacidade do veículo (Y kg)"

  Qualquer campo = null/0 → não aplica regra de peso (fail-open)

====================================================================
6. REGRA DE CUBAGEM
====================================================================

capacidadeVeiculoCompativel(..., cubagemOs, capacidadeM3):

  cubagemOs > 0 AND capacidadeM3 > 0:
    cubagemOs <= capacidadeM3 → ✅ COMPATÍVEL
    cubagemOs >  capacidadeM3 → ❌ capacidade_cubagem_insuficiente
    Mensagem: "Cubagem (X m³) excede capacidade do veículo (Y m³)"

  Qualquer campo = null/0 → não aplica regra de cubagem (fail-open)

====================================================================
7. COMPORTAMENTO NULL/0
====================================================================

Fail-open conservador:
  - OS sem peso (null/0) → não bloqueia por peso
  - OS sem cubagem (null/0) → não bloqueia por cubagem
  - Veículo sem capacidade (null/0) → não bloqueia
  - Moto com capacidade null → não bloqueia (campo estrutural ausente)

Ausência NÃO é classificada como "validado".
É classificada como "capacidade não informada" / "fail-open".

====================================================================
8. MOTOBOY
====================================================================

App envia capacidade_kg=null e capacidade_m3=null para moto (linha 799-800).
Gate: null × null → fail-open → não bloqueia.
Moto com capacidade null + OS sem peso/cubagem → OK.

14. PENDÊNCIAS
====================================================================

1. OS legada sem peso/cubagem preenchidos: gate é fail-open.
   Preenchimento dos campos na OS é pré-requisito para o gate atuar.

2. Veículo legado sem capacidade_kg/capacidade_m3 cadastrados:
   gate é fail-open. Atualizar cadastro do veículo é necessário
   para que o gate funcione.

3. Cubagem calculada pelo App (_cubagem = comp × larg × alt / 1e6)
   pode divergir de cubagem preenchida manualmente na OS.
   Unidades compatíveis (m³), mas precisa de coerência nos dados.
