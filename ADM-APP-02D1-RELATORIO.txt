5. ESTRATÉGIA ADOTADA (referência estável + signed URL temporária)
--------------------------------------------------------------------------------
Regra: persistir SEMPRE o path puro (ex.: doc_{prestadorId}_{tipo}_{ts}.ext /
foto_{prestadorId}_{ts}.ext); assinar APENAS em memória, TTL 600s.

  parseStorageRef(valor, bucketDefault)         -> {bucket,path,external,raw}
     * aceita URL pública legada e extrai bucket+path (regex /storage/v1/object/
       public|sign|authenticated|render/{bucket}/{path})
     * aceita path puro e bucket/path
     * rejeita file://, data:, caminhos locais, http externo
  referenciaEstavel(valor)                      -> path puro ou null
  resolverUrlDocumento(valor, {prestadorId})    -> assina (TTL 600) ou null
     * null se bucket != documentos_prestadores
     * null se path malformado
     * null se path não pertence ao prestador (T10)
  assinarStorageRef(ref, 600, sign?)            -> createSignedUrl
     * sign injetável (testabilidade); sem service_role; sem URL pública nova

Propriedade do path: o TMS e o APP GERAM paths já embutindo o prestadorId,
o que permite a guarda de propriedade (T10) sem consulta extra.
